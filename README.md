# 原初の海 — 最終帰還編

Godot 4.7.2 / GDScript / Compatibility で作る、Windows x86_64 向けのオフライン一人称海洋探索ゲームです。M1.5のホガラと既存の航法復旧を保持し、航法復旧、M2の装置安定化、**M3の帰還コア回収と最終帰還**まで遊べます。

浅瀬と回廊で金属片2個と航法ユニットを回収し、ポッドで航法を修理。その奥の**白濁の平原**では、糸庭虫の網を切ったり刃葉虫が削る切れ目を使ったりして制振フレームを回収します。残った網は窓喰いの突進を短時間止めます。**殻の墓場**では共鳴壺の音を六面這いへ伝え、空いた通路から空殻内の位相調整器を探します。双方に消耗品なしで使える迂回路があります。

航法復旧後は、二海域の接続付近にある**中継補給点**で酸素とスーツを補給できます。部品は救命ポッドへ持ち帰って保管し、端末で「装置を安定化」を選ぶとM2完了。さらに奥の**環状の裂け目**で環顎の予兆と横流れを読み、沈没調査艇の固定具を切って帰還コアを回収。別出口と岩陰を使って帰り、コアをポッドへ保管して帰還装置を起動します。帰還成功後も同じ海で15種の調査を続けられます。

任意のタンクII・カッター改良、手動ブイ6個、追跡部品の選択を追加しています。形態の参考と創作の区分は [M2の生物資料](docs/M2_SPECIES_SOURCES.md)、旧ホガラ資産は [制作手順](docs/ASSET_PIPELINE.md) を参照してください。

## Windowsで遊ぶ

[M3 Windows開発版を取得](https://github.com/tsutchi30-lang/primordial-sea/actions/runs/38115971509/artifacts/11693204336)（実装bcb4915、2026-10-18 05:54 UTCまで）。[画像・4本の入力動画](https://github.com/tsutchi30-lang/primordial-sea/actions/runs/38115971509/artifacts/11693549040) と [確認結果・保存期限](docs/PROGRESS.md) も参照してください。Actionsの `PRIMORDIAL_SEA_Windows_M3_<commit>` と `PRIMORDIAL_SEA_M3_Evidence_<commit>` は7日保存です。フォルダ全体を展開して `PrimordialSea.exe` を起動し、EXEとPCK・ライセンスを同じ場所に保持します。

M2安定化済みなら「続きから」でコア探索へ進めます。中継の入口から見える画面へ近づいて補給し、殻の墓場の奥へ潜ってください。[短い確認順路](docs/PLAYTEST.md) と [M3受入表](docs/M3_ACCEPTANCE.md) に詳しい操作と未確認事項を記載しています。

| 操作 | キー |
|---|---|
| 視点・泳ぐ | マウス、WASD |
| 上昇・下降・加速 | Space、C、Shift |
| 調べる・回収・ポッド端末・中継設備 | E |
| 観察器・カッター・誘餌・パルス・ブイ | 1〜5、ホイールで選び、左クリック |
| 緊急パルス / ライト | Q / F |
| 図鑑・持ち物 / ポーズ・マウス解放 | Tab / Esc |
| フルスクリーン切替 | F11 |

観察器は左クリックを約2秒押し続けると記録します。小型種は近づいて拡大してください。粘糸はカッターを選び、左クリックを1.2秒（改良後0.6秒）押し続けて切ります。重要部品は E で回収します。ポッドでは E で端末を開き、出発・修理・改良・装置安定化・最終帰還を選べます。

ポッド帰還時に資材を保管し、酸素・スーツ・パルス・誘餌を補給します。水面では外気呼吸へ切り替わり、酸素は減りませんが増えません。水中で終了・死亡した場合は最後のポッド保存点から再出発し、未保管の航法ユニット・M2部品・帰還コアは元の回収地点に戻ります。中継では携行品を保管せず、誘餌・パルスも補充しません。観察記録と設定は進行とは別に保存されます。

保存先は `%APPDATA%\PrimordialSea\`。旧M1/M1.5/M2からは「続きから」を選びます。最初の保存前に元のschema 1/2を版ごとのbackupへ原文退避し、schema 3へ移行します。未知の将来版は上書きしません。[移行と失敗時の扱い](docs/SAVE_MIGRATION.md)を参照してください。新規開始は現在の進行を上書きするため、引き継ぐときには選ばないでください。

## 開発・検証

Linux x86_64 の空の clone から、次を実行します。Bash、curl、unzip、Python 3、GNU coreutils、Git が必要です。

```bash
tools/verify.sh             # 固定版準備 → 音生成 → import → 本編の回帰試験
tools/export_windows.sh     # 同じ検証後、build/windows/ へ EXE/PCK と説明書を生成
tools/godot.sh --path .     # Linuxで本編を起動
tools/capture_visuals.sh    # Xvfb/OpenGLによる720p・1080pの画面生成
tools/capture_m3.sh         # M3代表画面・中継／回避／回収／帰還の入力動画
tools/capture_comparison.sh # 任意：M1.5の改善前後比較
```

初回は公式のエディタとtemplatesを取得・SHA512検証します。システムPATHのGodotに依存しません。開発環境で既に用意した版を利用する場合のみ `PRIMORDIAL_ENV_ROOT=/workspace/.primordial-sea-env` を設定してください。

- [ビルドと検証の詳細](docs/BUILD_AND_TEST.md)
- [Windowsでのプレイ確認手順](docs/PLAYTEST.md)
- [確認済み範囲・残る確認](docs/PROGRESS.md)
- [M3の構成と調整値](docs/M3_IMPLEMENTATION.md)

ホガラの専用モデルと材質は同梱GLB/PNGから読み込み、制作元のBlenderスクリプトも保存しています。通常ビルドにBlenderは不要です。その他の形状・シェーダー・音は同梱コードで生成します。Noto Sans CJKとGodotの出所・ライセンスは `assets/licenses/` に同梱しています。史実を参考にした生物でも、生態と配色には創作を含みます。
