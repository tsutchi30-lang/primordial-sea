# 実装と調整

## 本編の責務

`scenes/main.tscn` → `scripts/game.gd` が唯一の起動経路です。タイトル、潜水、帰投、修理、死亡、観察を接続し、`player/diver.gd` が衝突付き移動と相対マウス、`ui/interface.gd` が日本語UI、`progression/expedition.gd` が酸素・資材・重要品の状態を扱います。

`world/sea_world.gd` は固定シード503171の海底・岩・海綿・ポッド・残骸を生成します。地形はおよそ240×250m、海面0m、ポッド(0,1.6,0)、入口(0,-2,-5)、航法ユニット(0,-36,-130)。浅瀬から緩やかに深くなり、x=0の直進とx=18付近の迂回が通れます。M1.5では地形関数を保ち、遭遇区間の群落・殻片を `world/encounter_dressing.gd` に追加しています。外周では自然地形と徐々に強まる流れで戻すため、瞬間移動や透明壁はありません。

`ecology/ecosystem.gd` が7種の関係を接続します。小型種、群れ、ホガラ、窓喰いは別スクリプトで動きます。AIは本編の進行中にだけ `tick(delta)` され、ポーズ時に時計を進めません。群れには重い個別物理を使わず、砂煙と誘餌の数を制限します。種の定義と観察文は `data/species/species_catalog.gd` にあります。

## 初期値

- 通常2.8m/s、加速4.5m/s、プレイヤー断面0.6m。斜め入力を正規化し、カメラロールはしません。
- 酸素480秒、加速1.25倍、水面判定±0.3mのヒステリシス。酸素ゼロ継続8秒で死亡し、浮上で猶予を解除します。
- スーツ100、窓喰いの一撃28、被弾無敵2秒。Qと道具スロットのパルスは共通残数・クールダウンです。
- 航法修理はユニット1＋金属片2。一般素材の携行上限12、重要品は別領域。浅瀬資源は90秒で再生し、再出発時にも補充されます。
- 初期誘餌3、微生物膜で2補充（最大6）、ポッドで最低3。パルスは帰投ごと1。ブイ3。
- タンク改良は金属片2で600秒。修理前は航法用の金属2を残さないと改良できず、進行の取り合いを防ぎます。
- 生物観察は2.3秒。小型種の実寸を保持し、観察器の狭いFOVで拡大します。地形・殻による遮蔽を検査します。

## 保存の不変条件

進行JSONは `schema_version: 1`。航法状態は `wreck → carried → stored → repaired`。保存点に `carried` は書かず、帰還時には保管後の候補データを検証・保存してから、実際の資材と目標を更新します。修理とタンク改良も保存が成功してから確定します。失敗時はポッドの安全状態で資材を保持し、再試行パネルから同じ処理をやり直せます。死亡・水中終了で未保管の重要品を輸送しません。再ロードで二重取得・二重修理を防ぎます。

`save/save_store.gd` がJSONの型・範囲・版を検証し、一時ファイルから置換します。破損や未知版は読込エラーを表示し、勝手に上書きしません。観察の随時保存では進行を保存しません。設定も別JSONです。自動試験は `user://automated-tests/run-<pid>/` を使用します。

一般素材の携行上限は12、金属の保管上限は共通定数1,000,000です。採集・帰投・書込・読込で同じ上限を使い、超過分を消しません。schema 1の既存チェックポイントはそのまま読み込めます。酸欠8秒の警告はHUDの毎フレーム描画で観察状況より優先し、浮上・死亡で解除します。

## 見た目と音

Compatibilityで動く通常の霧・水面と砂地のshader・半透明膜を使用します。Forward+や外部ネットワークは実行時に不要です。小型種の吻・目・棘・脚、窓喰いの膜・硬い口器・付着粒子を個別に生成します。ホガラは専用GLB・8材質・部位別テクスチャへ移行し、制作元は `tools/art/`、通常importに必要な出力は `assets/` に同梱しています。詳細は [ASSET_PIPELINE.md](ASSET_PIPELINE.md) を参照してください。

`hogara_gait.gd` が一本ずつの踏み出しと独立した地形接地を計算し、`hogara.gd` が体重移動・休息予兆・安全な退出を接続します。`hogara_model.gd` が関節、帆、濾過房を明示的deltaで動かします。屋根・支持脚には可視メッシュ由来の凸形状、くびれた肋には可視メッシュの三角形による衝突を使い、動く部位に同期します。公称1.1mの開口候補を実際のプレイヤー形状で検査し、脚で塞がれた候補は退出に使いません。出口を確保できないときは降下を取り消します。観察の照準は対象自身の殻を除外し、地形の遮蔽は保持します。

音10本はPython標準ライブラリで決定的に生成します。Master/BGM/SFX/UIを分離し、環境・警告・パルス・膜・ホガラの休息・足の接地・取得・完了・UIから再生します。接地砂と足音は接地イベントだけで発生し、足元の砂は捕食者を露出させる生態上の砂煙から独立しています。聴取確認とWindowsでの体感は別試験です。

## 今回簡素にした範囲

ポッド内の操作は一つの固定端末、補給食は整備案内、装備成長はタンク1段階です。地形は手設計のルートに生成した装飾を加えます。自由建築、戦闘による経験値稼ぎ、常時空腹、M2/M3の未実装メニューはありません。25〜40分は初見観察込みの目標で、プレイ時間の実測値ではありません。
