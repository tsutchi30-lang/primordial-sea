# M2 装置安定化編の実装

起点はM1.5の `5b6aefbd92da3381b703b8cd9f4d75d042b967d8`。航法復旧、既存7種、専用ホガラ資産と三脚歩容を保持し、航法復旧後の探索を追加します。M3の帰還コア・全編帰還は未実装です。実行結果と証拠は [受入表](M2_ACCEPTANCE.md) に分けて記録します。

## 本編の流れ

航法修理 → 白濁の平原／殻の墓場 → 制振フレーム／位相調整器を任意の順で回収 → 中継で酸素・スーツ補給 → 救命ポッドへ帰投・保管 → 装置安定化 → 継続探索。

部品は独立した重要品枠です。一般素材を満杯にしても回収できます。Eで4m以内、照準と地形・生物殻による遮蔽を確認します。ポッドに片方だけ保管した後の死亡では、保管済みは維持し、未保管だけ元の場所へ戻ります。

## 海域と経路

`data/biomes/world_map.gd` を海域・境界流・ブイ範囲・HUDの共通定義にします。横範囲は x=-150〜150、z=-460〜60、ブイのyは-260〜10。カメラfarは620m。既存の重要地形（z≥-150付近）とseed503171を維持し、旧遠端の押し戻しを新境界へ移しました。

| 地域 | 地点と遊び | 経路 |
|---|---|---|
| 白濁の平原（z=-175〜-298） | 白い泥盆地、粘糸の岩柱、輸送箱、骨状の岩、ウィワクシアの泥棚 | 網を切る／刃葉虫が開く主経路、西側の網なし迂回路 |
| 接続部 | 固定中継（x28,z-275）。見える入口と照明、細い安全な開口 | 実際の開口から泳いで入り、近づいてE |
| 殻の墓場（z=-298〜-460） | 大小の古い空殻、共鳴壺の列、鉱物の巣、マーレラの棚 | 主空殻の前方入口、東の破れ目、後方出口 |

制振フレームは(-12,z-225)、位相調整器は(25,z-365)。yは地面からの高さとして定義し、実地形の床高で配置します。主空殻には内部床・天井・壁と三つの出口があり、部品は内部に置きます。ポッドと中継を結ぶ移動では、既存回廊のホガラ付近で床上9mの開けた水中を通り、動く脚や殻との接触を避けます。`WorldMap.route()` は撮影専用の抜け道ではなく、設計された通常通路を示すwaypoint列です。

## 新しい生態

| 種 | 本編で起きること | 上限・終了条件 |
|---|---|---|
| 糸庭虫 | 五枚の板を持つ約40cmの本体、粒子の付いた粘糸。網の実体積内で速度0.55倍。カッターで区画を切り、繊維を一つ落とす | 減速は重複しない。1.2秒、改良後0.6秒の長押し。燃料なし。切断済み区画から重複報酬なし。再生時に人や捕食者を閉じ込めない |
| 刃葉虫 | 重なった葉状の板を開閉し、実際に網へ近づき1.6秒の採餌で切れ目を開く。誘餌へ短く寄り、脱皮殻を落とす | 誘餌8秒／巣から12m、再誘導22秒待ち。防御0.8秒予兆→8損傷一回。脱皮は90秒間隔・一個体3回まで |
| 共鳴壺 | 壺状の群体が膜で濾過。3m以内の加速→膜の膨張→鳴動、近くの壺へ伝わる | 予兆1秒、伝播9m・最大2hop、刺激TTL6秒、同じ刺激に一回、休止12秒。音と膜の両方で示す |
| 六面這い | 六角板と多方向の脚。音源へ物理移動して入口を空ける。有限の鉱物を巣へ運び、休むホガラの低い外縁を掃除 | 反応15秒／巣から15m、到着後4秒調査、閉塞・到達不能で中止。0.8秒予兆→10損傷一回。原物の鉱物を移す |
| ウィワクシア | 3〜5cm、背の鱗と棘・柔らかな腹側、泥棚を遅く進んで採食 | 3個体。観察器の近接拡大で実寸を保持 |
| マーレラ | 1.5〜2.5cm、頭の長棘・26体節・細い付属肢、空殻の棚で漂う粒子を集める | 3個体。図鑑に形態資料と創作行動を分けて記載 |
| アノマロカリス | 前方関節肢・側方ひれ・腹側口・尾扇。専用の小さい軟体獲物へ接近し、捕らえて摂食 | 1個体、専用獲物4個・45秒再生。捕食移動は実衝突、接近時間9秒・閉塞1.5秒で中止。既存灯粒虫は消費しない |

平原の追加窓喰いは通常の突進・捜索・帰巣を使用します。実移動区間と残った網が交わると3.5秒絡まり、膜が引かれる姿勢を見せ、脱出時にその網を破ります。拘束は緊急パルスと別の状態で、追跡の時計をリセットしません。

すべてのAI・網再生・採集物・音の予兆は本編のゲーム時間から更新します。ポーズ、図鑑、整備、フォーカス喪失では進みません。図鑑の行動追記は識別済みの実対象を近距離で照準・遮蔽確認できた場合だけです。

## 素材・装備と保存

| 項目 | 条件／数量 | 結果 |
|---|---|---|
| 金属片 | 携行12、保管1,000,000 | 航法と装備改良に使用 |
| 補修繊維／殻片 | 各携行8、保管各1,000,000 | 切断・採餌された網／刃葉虫の有限脱皮から回収。満杯なら地面に残る |
| タンクI（既存） | 金属2、航法未復旧時は修理用2個を残す | 480→600秒 |
| タンクII | 航法復旧＋タンクI、金属3＋補修繊維2 | 600→780秒 |
| カッター改良 | 航法復旧、金属2＋殻片2 | 切断1.2→0.6秒 |
| 安定化 | 航法復旧＋二部品をポッドへ保管、追加素材なし | 二部品を組込済みにして完了。灯りが一定になりポッド音が静まる |

部品は `world → carried → stored → installed`。資材や部品を保管・消費する取引は、完全な実行中状態のコピーに操作を適用し、保存成功後に本編へ確定します。保存失敗は安全なポッドで保持し、同じ操作を再試行します。schema1→2移行、原文退避、将来schema拒否は [SAVE_MIGRATION.md](SAVE_MIGRATION.md) を参照してください。

中継は保存済み航法復旧後のみ使用可能。生存中の酸素・スーツと酸欠警告を回復します。現在地、携行品、誘餌、パルス、海域状態、ポッド保存点を変更しません。中継で補給しても、死亡・終了時の部品は自動輸送されません。

## 責務

`game.gd` が入力と取引の接続、`m2_controller.gd` がM2の採集物・中継・端末/図鑑内容、`Expedition` が進行、`SaveStore` が永続化を担当します。平原・墓場・実在モデルは独立managerとして `ecosystem.tick()` から更新します。Map、Items、Upgradesの定義をUI・保存・本編で共有し、旧ホガラの資産と歩容処理を維持します。
