# Windows 実機確認 — 原初の海 航法復旧・装置安定化編

Windows 実機でのマウス、音、操作感は確認待ちです。Linux の import、ロジック試験、実描画、Windows export と区別して記録してください。

## 起動と保存

配布フォルダを全て展開し、`PrimordialSea.exe` を起動します。PCK が別ファイルの場合は EXE と同じ場所に置いてください。インターネット接続は不要です。保存先は `%APPDATA%\PrimordialSea\`。新規開始は既存の進行を上書きします。水中で終了すると最後のポッド保存点から再開します。

## 旧セーブからM2を見る短い順路

1. フォルダを展開して起動し「続きから」。旧保存は同じ `%APPDATA%\PrimordialSea\` から読みます。航法未完了なら以下のM1順路で修理。航法修理済みなら「制振フレームを探す」が主目標になります。
2. 艇の残骸のさらに奥へ泳ぎ、深度60m前後の白濁の平原へ。回廊のホガラ付近では、殻と脚から離れた上側の開けた水中を通れます。白い盆地、糸の岩柱、壊れた輸送箱を目印にします。網に触れても視点と道具は操作できます。カッターの左クリック長押しで切り、補修繊維を E で採集。刃葉虫の自然な採餌でも切れ目ができます。
3. 残った網を挟んで窓喰いの収縮予兆を観察し、絡まっている間に離れます。パルスなしなら外縁を回る道も使えます。箱の開いた側から制振フレームを E で回収。金属などの持ち物が満杯でも部品は独立して持てます。
4. 平原奥・東寄りの中継設備へ。入口から近づいて E、酸素とスーツを補給。誘餌・パルス・携行品はそのままで、現在地も変わりません。部品はまだ保存されていません。
5. さらに奥の殻の墓場へ。安全な壺の3m以内でShift加速し、膜の膨張→音→休止を観察。大きな空殻の入口脇にある壺の列を鳴らすと、六面這いが音源へ歩きます。通路が空いてから進み、位相調整器を E で回収。東側の破れ目と奥の出口も使えます。
6. 中継で再補給し、ポッドへ持ち帰ります。危険を感じたら片方だけ先に保管しても構いません。二部品の回収順は自由です。帰投後、端末で安定化部品2/2を確認し「装置を安定化」。完了表示、一定になる装置の光、探索継続を確認します。
7. タイトルから再開し、安定化と部品の組込を確認。任意で補修繊維2＋金属3からタンクII（タンクIが前提）、殻片2＋金属2からカッター改良を行います。殻片は刃葉虫の脱皮で採集できます。
8. 平原入口の低い泥棚でウィワクシア、空殻内の貝片棚でマーレラを近接拡大。平原の奥ではアノマロカリスが専用の小さな獲物を捕らえます。Tabの全14種を選び、未観察・識別・行動確認の区分を確認してください。

部品はポッドに保管するまで死亡・水中終了で元の場所へ戻ります。中継補給後も同じです。Aだけ保管してBの回収に失敗した場合、Aの保管は維持します。保存失敗画面では手元の進行を保持し、「保存を再試行」で確定できます。

M2の初見プレイ時間、迷いやすさ、音の大きさは人による確認待ちです。自動経路試験の経過時間を初見プレイ時間とみなさないでください。

## 20〜40 分の確認手順

1. タイトルから新しく始め、ポッドで事故説明、航法ユニットと金属片 2 個の修理目標、基本操作が読めることを確認。
2. 出発し、WASD・Space・C・マウスで泳ぐ。岩と海底をすり抜けないこと、斜め移動が異常に速くならないことを確認。
3. Shift で加速し、そのまま Esc を押す。メニュー中に Shift を離して再開し、加速が残らないことを確認。Tab の図鑑でも繰り返す。
4. 泳いでいる間に Alt＋Tab。ポーズになり、酸素と生物が止まり、マウスが解放されることを確認。戻っても「再開」を押すまで止まることを確認。
5. F のライトをオン・オフし、道具切替、ポッド出入り、セーブからの再開後も操作できることを確認。
6. 酸素を少し消費してから水面へ上がる。外気呼吸中は残量が減らず、増えもしないことを確認。ポッドへ入ると酸素と耐久が回復することを確認。
7. 浅瀬でオパビニア、ハルキゲニア、三葉虫を観察器で拡大し、図鑑に実在モデル区分と観察した行動だけが記録されることを確認。金属片を 2 個回収。
8. ホガラの全身を眺め、腹側へ自分で泳いで入り並走する。入口から自由に出られること、休息予兆の後に閉じ込められないことを確認。
9. 安全な距離から窓喰いの輪郭、灯粒虫の消灯、捕食前の収縮を見る。泥ほどきの 3 m 以内で Shift 加速し、砂煙で輪郭が露出し、しばらくして元へ戻ることを確認。
10. 灯粒虫の近くへ誘餌を置き、群れが移動し、それを追う窓喰いが通路を空けることを確認。Q の緊急パルスが近距離で離脱時間を作ることを確認。
11. 回廊の短い経路と、岩やホガラを利用する迂回経路を通り、艇の残骸で航法ユニットを回収。目的が帰投へ変わることを確認。
12. ポッドへ戻り金属片 2 個と航法ユニットで修理。「航法復旧編 完了」と表示され、全編帰還とは表示されず、その後も探索できることを確認。
13. タイトルに戻り「続きから」。完了状態、保管素材、ブイ、図鑑、設定が復元されることを確認。

## ホガラ改善版の短い確認

1. 新規開始または以前のポッド保存点から出発し、艇の信号へ潜る。浅瀬の海綿群落を越え、深度20m前後の右側で巡回する帆を探す。タイミングを逃しても巡回で再び会えます。
2. 15m程度離れた通常FOV80°で、帆の欠けと三本の太い脚が読み取れるかを見る。3〜5mへ近づき、殻の成長筋・節・関節・帆の薄さを見比べる。
3. Fでライトを消し、見えている肋の隙間から腹側へ入る。中央を泳ぎ、天井・濾過房・出口を見る。ライトを点け、素材の違いも見る。
4. 自分のWASDで並走して左右の隙間から出る。プレイヤーやカメラが自動で追従しないこと、腹側でも酸素が減ることを確認。
5. 足元を横から数歩見る。接地中に滑らないか、足が沈まないか、踏み出しと接地の砂・低い音が合うかを確認。
6. 筋の光が弱まり減速したら外へ出る。約5秒の予兆、体を休める動き、再び立って歩き始める動きを見る。中央以外の隅からも退出し、動く肋に押し込まれないかを確認。
7. 設定で「粒子を減らす」を有効にして繰り返す。窓喰いの縁と捕食予兆、泥ほどきの砂煙で付着が増える違いが残ることを確認。

保存失敗の画面が出た場合は、ゲームを終了せず保存先の容量・アクセスを確認し、「保存を再試行」を選びます。修理の金属は保存成功まで消費しません。タイトルへ戻ると未保存の進行は失われるため、画面の説明を確認してください。通常セーブを変更して故障を作る必要はありません。故障と再試行は隔離した自動試験で検証します。

## 追加の回帰確認

| 項目 | 操作と期待結果 | 結果 |
|---|---|---|
| 死亡前の重要品 | 航法ユニットを取得し帰投前に死亡。再開後は残骸へ戻り、ポッドに自動輸送されない | 確認待ち |
| 保管後の重要品 | 航法ユニットを保管してから死亡。保管済み状態を維持し、残骸で二重取得できない | 確認待ち |
| 金属不足 | 金属片なしで航法ユニットを保管。浅瀬の回収目標が分かり、必須素材を補充できる | 確認待ち |
| 酸欠の猶予 | 酸素 0 の警告後、8 秒以内に浮上すれば助かり、再潜水では猶予が再開する | 確認待ち |
| 捕食者から離脱 | 横回避、岩の陰、ホガラ、パルスを使用。突進後に隙があり、追跡が終了する | 確認待ち |
| 表示サイズ | 1280×720 と 1920×1080、ウィンドウのサイズ変更、F11 切替。HUD・図鑑・設定・完了画面の日本語に欠けや豆腐がない | 確認待ち |
| マウス | 左右 360 度、上下限、Esc、Alt＋Tab、死亡、ロード。再開クリックで道具を消費しない | 確認待ち |
| 設定 | 感度、上下反転、FOV、揺れ、各音量を変更し再起動。値が保存され、消音が効く | 確認待ち |
| 音 | ポッド、泡、ホガラ、膜の収縮、パルス、帰投音を聞く。音量バスごとに変更可能 | 確認待ち |

確認時は Windows 版、CPU/GPU、解像度、ゲーム版、commit、開始・終了時刻、選んだ経路を記録してください。初見 25〜40 分は目標値であり、測定済みのプレイ時間ではありません。

不具合報告には、直前の操作、画面、再現回数、`%APPDATA%\PrimordialSea\logs\godot.log` を添付します。セーブを退避する場合はゲームを終了してから行い、元ファイルを削除せずコピーしてください。
