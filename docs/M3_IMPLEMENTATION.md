# M3 — 最終帰還編

起点は未マージのM2 PR #3、`codex/m2-ecology-expansion` の `208a292faa0dc56bc7efc9c4cf09af691ae81500`。M3は同ブランチをbaseとする積み重ね変更です。Godot 4.7.2、Compatibility、Windows x86_64を維持します。

中継は見える画面にMarker3Dを置き、ヒント・E・補給処理が同じ距離・角度・遮蔽条件を使います。保存済みの航法復旧が必要です。正面0.5〜2.5m／斜めから使え、壁越しと裏側は拒否。酸素とスーツだけを回復し、満タン時は成功通知を連打しません。

整備画面は主目標、現在必要な操作、具体的な不足条件を先頭に表示します。改良と記録を分け、閉じるボタンをスクロール外に固定しました。拾う対象とヒントは共通の照準・遮蔽照会を使い、重要品取得の通知を地域案内より優先します。取得時には短い縮小・持ち上げ、固定具には切断進捗と開く腕を表示します。

## 海域・経路

墓場の奥に深度約244〜279mの環状の裂け目を追加。旧海域の地形グリッド間隔を保持して南へ132m拡張しました。棚から岩柱、沈没調査艇、流れを見下ろし、北入口への主経路か西側の迂回を選べます。船は13×28m、実天井・床・別々の壁を持ち、北入口と東の開口は約23m離れています。天井越しの回収と壁越しの攻撃はできません。

横流れは中心 `(3,-258,-479)`、最大1.35m/s、境界で滑らかに減衰。人と環顎へ同じベクトルを加え、通常の2.8m/sの泳ぎで逆行・退出できます。既存の境界帰還流と重複加算しません。地形・ブイ・ルート・信号はWorldMapの共通座標です。

基本タンク480秒・未改良カッター・誘餌0・パルス0の入力経路では、中継↔棚249.43秒（補給前48.0%）、主経路コア回収313.82秒（34.6%）、迂回358.67秒（25.3%）。途中teleportなしで別出口・岩陰・棚・中継へ戻り、主経路ケースはその後ポッドまで泳いで保管します。余裕は補給前の値です。初見の所要時間や難易度の測定ではありません。

## 環顎

10.4mの単一連続帯を曲げ、前半身を輪にします。内側の実体歯とヒレ、節色を含む専用手続きメッシュで、近距離20Hz／遠距離5Hz。シミュレーション時計は既存のecosystem.tickに集約しています。

| 要素 | 現行値と処理 |
|---|---|
| 通常発見 | 実移動入力、8m・前方140°、4m以内の近接、遮蔽あり |
| 加速音 | 実際のShift泳ぎ、16m以内、壁で遮断 |
| 切断刺激 | 開始・解除・取得の局所刺激。壁越し減衰、記憶地点の調査のみ |
| 注意／予兆／固定 | 0.65秒／1.6秒／最後の0.7秒は狙いを更新しない |
| 突進 | 9m/s、最大1.4秒・12m・固体接触で終了。大きいdeltaも上限で制限 |
| 被弾 | 口の掃引球＋遮蔽照会、35ダメージ、一突進一回。体節で重複しない |
| 回復／捜索 | 4秒／最大2.5秒 |
| 遭遇限界 | 全体18秒・最大2突進・拠点から44m |
| 退避 | 実移動して退避点へ。2秒停滞で別経由点、船内では開口から後退してから旋回 |
| 再捕捉 | 退避点到達後10秒待つ |
| 捕食 | 近い実在の灯粒虫の群れを捕え密度を減らす。35秒の捕食間隔 |

観察は既存の距離・視線・遮蔽・観察入力を通し、実際の行動イベントだけを記録します。図鑑は15種。遠方のコア取得で強制的に襲来する処理や、敵を倒す必須条件はありません。

## 回収・保管・帰還

M2の2部品と独立した `return_core` は `world → carried → stored → installed`。先取り可能で一般携行枠を使いません。固定具はカッター1.2秒／改良0.6秒、次にEで回収。道具切替・距離・視線・ポーズで切断進捗を中断し、解除後の連打で複製しません。

保管・最終帰還は完全な実行状態の複製に変更を適用し、保存成功後だけ確定します。`game_completed` の保存後に28秒の帰還演出を開始。光・装置・窓外と4段階の日本語表示、実記録数の成功画面、Escスキップ、フォーカス喪失時停止があります。クリア後は同じ海へ戻り、通常探索と保存を継続できます。次回ロードで演出は再生しません。

schema1/2→3、原文退避、失敗時の保持は [SAVE_MIGRATION.md](SAVE_MIGRATION.md)。実施した検証と限界は [M3_ACCEPTANCE.md](M3_ACCEPTANCE.md)、操作手順は [PLAYTEST.md](PLAYTEST.md) を参照してください。

## 主なファイル

`m3_controller.gd` がコア・帰還取引、`return_sequence.gd` が演出、`rift_dressing.gd` が船と海域、`kangaku.gd` / `kangaku_form.gd` が行動と姿、`rift_ecology.gd` が実在群れと局所刺激を担当します。既存のホガラGLB、M2生態、装備定義、音生成を継続利用します。追加アセットに外部サーバーやランタイムダウンロードは必要ありません。
