# M2の残る品質確認

実装・自動検証・実描画・Windows実機確認は [M2_ACCEPTANCE.md](M2_ACCEPTANCE.md) で区別します。本書は実施していない確認を合格にするものではありません。

| 優先 | 課題 | 次の確認 |
|---|---|---|
| 高 | Windows上の起動、物理マウス、Alt+Tab、音声デバイス | 配布EXE/PCKでPLAYTESTの短い順路を行う。Linux exportと分ける |
| 高 | 初見での網・壺の手がかり、中継の発見、酸素の判断 | 人による航法復旧→二部品→安定化。自動操縦の経過時間は初見時間に使わない |
| 中 | 新種の手続き生成モデル・空殻・輸送箱の材質 | 720pでは網・殻の開口・種の輪郭を目視。ウィワクシアの鱗の板状感、マーレラの細い付属肢、設備の平坦な材質は磨き込みが残る。実機で距離感と糸の視認性を確認。M1.5ホガラと同密度への全面更新は後段 |
| 中 | 共鳴壺の音、六面這いの警告、低音のバランス | ヘッドホンとスピーカーで聴取。目視で手前の膜と輪を確認。遠い壺の連鎖の輪は小さいため、音量0でも連鎖と姿勢の予兆が読めるか実機で確認 |
| 中 | Windows実GPUの1080p性能 | GPU/ドライバ/renderer/設定/区間を記録して平均とp95を測る。Linux llvmpipeは別記 |
| 中 | 720p図鑑の長い一覧、端末の改良理由 | キーボード・ホイールで14種と全操作に到達し、文字切れ・フォーカスがないか確認 |
| 低 | M3の帰還コア、最深部と全編帰還 | 今回は未実装。M2完了を最終帰還と表現しない |

実装上の不具合が検証で見つかった場合は、残課題へ移して済ませずM2の必要範囲を修正します。自動再生・静止配置・オフライン動画・実時間計測はそれぞれ条件を記録し、Windows実機の操作や聴取と区別します。
