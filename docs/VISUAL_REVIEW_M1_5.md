# M1.5 見た目・動く本編の確認記録

基準はM1の `7a2375487f39cdb17356c795cb7a6a8659b622ba`。Godot 4.7.2 stable、Compatibility、Linux/Xvfb/Mesa llvmpipeを使います。生成成功、静止画目視、時系列フレーム目視、入力・衝突の試験、Windows実機を別の結果として扱います。

## 比較条件と見る順序

`build/m1-5/before-standard/` と `after/` に同条件19組、計38枚を保存します。S01・S02・S05は1280×720と1920×1080、その他は1920×1080。seedは4702、地形seedは503171、通常FOV80°。カメラ位置・向き・解像度・ライト・粒子設定・ホガラのルート開始位置と向きを前後で機械照合します。光と地形の材質の変更そのものは比較対象です。

静止画は通常本編を起動後、生態を初期状態で止めてカメラを固定した検査配置です。S08は捕食者を帆の背後へ置き、S07の砂付着は本編の砂煙・露出処理を呼びます。画像はViewportからの未加工PNGです。補助一覧だけを縮小・注記し、元PNGを残しています。

最新の前後19組を一覧で目視し、主要720p画面と1080pの殻・関節、帆の表裏、腹側、足底、透明面の重なりを元解像度でも確認しました。丸みのある上殻、骨色の支持脚、地面に届かない緑の肋、暗い濾過房、筋のある半透明の帆を読み分けられます。脚の接地影と腹側の出口が見え、日本語HUDの欠けは見られませんでした。近距離の群れの光が画面を覆う問題、成長縁の食い込み、足底が画面下端で切れる撮影位置を修正して再撮影しています。

## ロジックと本番移動の範囲

`tools/verify.sh` のsmokeは本編の航法ユニット回収→死亡→再回収→帰投→保存→修理→完了→再開、観察、入力解除、酸素、誘餌、砂煙、捕食者を検査します。進行用fixtureでは試験地点への移動を使います。通常セーブは変更しません。

新しい歩容試験は130秒の生態時間で、接地中の足の最大移動0、地形接地誤差0、着地回数31/33/32を計測しました。一本だけの踏み出し、自然な旋回・5秒予兆・停止・再開、実表示の足底位置を確認します。6開始位置の退出、閉塞時の休息取消、手動操作の優先、途中侵入での降下取消は専用fixtureで別に検査します。すべての地形・プレイヤー位置を網羅した証明ではありません。

ポッドからの到達再生は新規開始と通常の出発処理から移動します。遭遇・歩行映像は最初の潜水者位置だけを検査用に設定し、その後は `Input.action_press/release` → 本番Diver → `move_and_slide` を通します。視点角は滑らかに自動操作します。途中の位置書換え、ホガラの速度・state・時計の上書きはありません。酸素、衝突、生態、捕食者が動く自動操作です。Windowsで人が遊んだ映像ではありません。

## 遭遇映像の確認

`motion/encounter.mp4` は1280×720、24fps、1,065フレーム、44.375秒、音声トラック付きです。生態時間44.02秒、移動59.44m、酸素480→436秒。腹側への入場、9.18秒の滞在、6.35mの並走、退出を本番処理とログで確認しました。0〜42秒の2秒刻みフレーム列を目視し、接近→殻と関節→開口→腹側→退出の流れとHUDを確認しました。退出直後は外を向き、最後は右の岩が一部を覆うため、休息と再始動は別の足元映像も使います。

これはMovie Makerによるオフライン収録です。映像の補間、早回し、色補正を行っていません。補助画像は元のフレーム番号とPTSから抽出し、対応を `selected-frames.json` に記録します。ここで実施したのは時系列フレームの目視であり、連続動画の実時間再生・聴取の検収ではありません。

## 足元・休息・実時間性能

`motion/gait.mp4` は1280×720、24fps、1,113フレーム、46.375秒、音声トラック付きです。全区間の2秒刻み、5〜8秒の接地付近の8fps抽出、24〜31秒の休息移行を時系列で目視しました。足の持ち上げと置き直し、体の移動、帆と房の変形、減速して休み再び歩く流れが見えます。自然な遷移の記録は予兆24.90秒→着床29.92秒→休息31.93秒→上昇38.95秒→歩行40.97秒です。

接地砂が足底の内側に隠れる問題を原寸動画フレームで発見し、地面法線に沿う足外周の小さな輪へ修正しました。修正後の通常入力再生の5.75秒・6.25秒の原寸フレームで、足外側へ出る控えめな砂を目視しました。粒子は着地時だけ生成し、低粒子では18個から6個へ減らします。遊びに使う砂煙の状態には影響しません。最終ソースで2本の映像を再収録し、修正した砂を原寸で再確認しました。全収録入口が終了0・`MOTION_OK`で完走しました。CIでも同じ入口を使います。

独立した実時間計測はLinux/Mesa llvmpipe LLVM 19.1.7（256 bits）、Compatibility、1920×1080、FOV80°、ライトOFF、通常粒子です。1秒のウォームアップ後112フレームの平均218.884ms（約4.57fps）、p95 241.508ms、p99 341.231ms、最大1,171.056msでした。ゲーム内15秒に壁時計24.703秒かかっています。ソフトウェア描画での測定であり、Windows実GPUやオフライン動画の出力24fpsと同一視しません。最終ソースの測定値は同梱 `motion/metrics-manifest.json` でも確認できます。

音声はAACトラックの存在・時間・非無音の波形まで確認しました。スピーカーやヘッドホンによる聴取は未実施です。
